# 修正 PDF 重建结果

当前目录里是一篇论文的 PDF 与规则脚本对它的重建结果：

- `original.pdf`：原文，只读。
- `main.tex`：规则脚本写出的英文 LaTeX，目标是编译后与原文内容一致、版式接近。
- `crops/`：从原文截出的矢量小块，只读。正文里的 `\im{编号}{下沉量}{提示}` 是一段行内公式的截图，提示是它在原文文字层里的字符；行间公式、图、表、算法、参考文献用 `\includegraphics{crops/...}` 整块插入。

规则脚本会出错，常见的是：一段话被拆成几段；一行里的公式碎片落到别处，形成孤立的字母、符号或空行；标题、脚注、图注识别错；个别词丢失或重复；截取区域漏掉或多带了旁边的文字。你的任务是对照原文逐页找出这些错误，只改 `main.tex` 把它们改正。

## 工具

用 `python3` 运行下面的脚本（它带有 PyMuPDF）：

- `python3 .skills/reconstruct_fix/check.py`：编译 `main.tex`，输出页数、单词召回率与精确率、缺字数、阅读顺序分数和通过与否（`PASS` 或 `FAIL`），以及缺失和多出的词、顺序错乱处的原文片段、缺了提示字符的行内截图。通途在会话结束后用同一套核对重新判定。
- `python3 .skills/reconstruct_fix/render.py 1 2 3`：把原文与重建结果的指定页并排渲染成 `cmp-<页>.png`，左边是原文，右边是重建结果。用 Read 工具看图。
- `python3 .skills/reconstruct_fix/crop.py <页> <x0> <y0> <x1> <y1> <新名字>`：从原文指定页按坐标（单位 bp，原点在左上角）截出一块新的矢量截图，写到 `crops/<新名字>.pdf`，并打印截取区域里的文字。截图范围错了（漏掉一部分或带进旁边的正文）时，用它重截，再在 `main.tex` 里引用新文件。新名字用 `fix-` 开头，不要覆盖已有文件。坐标可以先用 `render.py` 看图估计，再看打印出的文字确认范围。

## 做法

1. 先运行 check.py，再逐页渲染对照，记下每页的错误。重建结果与原文的分页会有偏移，按内容对照，不按页码对齐。
2. 只改错的地方。不要重写整段，不要改动 `\im` 与 `\includegraphics` 引用的已有截图文件；截图范围错了就用 crop.py 重截一个新文件；碎片可以删除或移回它所属的位置。缺了原文里的公式而没有对应的截图时，用 LaTeX 公式写出它。
3. 正文文字必须与原文逐词一致，不要改写、不要翻译。
4. 改完再运行 check.py 与 render.py 复查，check.py 输出的第一行应以 `PASS` 结尾。召回率与精确率都应在 0.99 以上，页数与原文相差不超过一成。
5. 结束前写 `notes.json`：`{"notes": [{"where": "...", "problem": "...", "resolution": "...", "suggestion": "规则脚本应怎样改"}]}`，逐条记下你修正的错误类别，suggestion 写规则脚本可以怎样避免它。
