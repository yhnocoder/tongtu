\begin{abstract}
This fixture exists so that the fetch stage sees a source tree with genuine
content. The pdfpages shell heuristic inherited from v2 flags any source whose
total .tex payload is implausibly small, so a fixture that is too short would be
routed to the fallback path and every unpacking assertion would test the wrong
branch. The prose below is therefore deliberately padded to a realistic size.
\end{abstract}

\section{Introduction}
Deterministic pipelines are easier to cache, resume and debug than agent-driven
ones. The fetch stage is the first link: it downloads an e-print tarball, sniffs
its magic bytes, and lays the source tree down under \texttt{src/} without ever
writing outside the working directory.

\section{Method}
We consider the archive $A$ and its members $m_1,\dots,m_n$. A member is
extracted only when its normalised path stays inside the destination root:
\begin{equation}
  \mathrm{safe}(m) \iff \mathrm{resolve}(\mathrm{dest} / m) \subseteq \mathrm{dest}.
\end{equation}
Symbolic links, hard links and device nodes are rejected outright, since a link
pointing at an absolute path outside the tree is an escape hatch that a purely
lexical path check would not catch.
