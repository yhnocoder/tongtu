class Manifest(BaseModel):

    warnings: list[str]
    message: str

precompile把原文变成一份带中文排版设置、能编译通过的单文件 LaTeX，产出基线work（失败时）
任务
  1. 选主文件：src/ 下含 \documentclass（注释外）的 .tex 是候选；多个候选时取唯一含 \begin{document} 的，再不唯一取名为 main.tex 的。一个候选都没有 → main_not_found；仍不唯一 → main_ambiguous，message 列出全部候选
  2. 展开成单文件：latexpand --keep-comments --fatal 把 \input / \include 全部内联；主文件旁有同名 .bbl 且全文恰有一处 \bibliography{} 时，把 .bbl 内容替换到该命令处。展开结果必须非空且含 \begin{document} 与 \end{document}，否则 expand_failed；仍残留 \input 的行数记 warning
  3. 注入中文排版设置：在 \documentclass 之后插入 xeCJK 设置（仓库自带的霞鹜文楷作主字体，Path 指向编译树里的 fonts/；行长断行按中文规则）。文档已经用 xeCJK / ctex 一族则不注入；用旧式 CJK 宏包则先剥掉再注入。放在这一步而不是 compile，是让宏包冲突在翻译之前、在本阶段的修复会话里暴露并修掉：之后 compile 与 precompile 的差别只剩正文文字，再出错只可能是译文引起
  4. 搭编译树 build/sandbox/precompile/：src/ 整体拷贝，写入 flat.tex，拷入仓库的 fonts/
  5. 首次编译：latexmk -xelatex -interaction=nonstopmode flat.tex，超时 600 秒。通过的判据：退出码 0、flat.pdf 非空、flat.log 解析出的页数 > 0。latexmk 跑不起来或超时 → compile_failed。校验编译通过后，编译树的 fonts/ 整目录拷出为正式产物 build/fonts/
  6. 不通过 → 修复会话：拉一次 agent work（角色 precompile_fix），现场就是编译树，agent 自己读 skill 与 flat.log、改 flat.tex；会话结束 latexmk -C 清掉中间产物，再校验编译一次，结论只认这一次，仍不通过 → compile_failed。会话的改动只留在编译树里，不传到 compile（compile 的编译树仍从 src/ 搭）；会话以 error / timeout 结束记 warning，判定仍由校验编译给出

# 一次校验编译的结果。precompile 记原文的，compile 记译文的，同一个类，并排可比。
class CompileReport(BaseModel):
    pages: int
    pdf_bytes: int
    overfull_hboxes: int
    undefined_references: int
    undefined_citations: int
    missing_characters: int
    duration_seconds: float

# 一次 agent 修复会话的结局。拉起过才有。
class FixSession(BaseModel):
    stop_reason: "finished"|"timeout"|"error"
    model: str
    duration_seconds: float

class PrecompileManifest(Manifest):
    status: PrecompileStatus
    main_file: str                      # 判定出的主文件
    report: CompileReport | None         # 校验编译通过才有
    fix_session: FixSession | None       # 拉起过才有
    # warnings 含：bbl 内联与否、残留 \input、会话改动了 flat.tex 之外的文件；message：失败原因，main_ambiguous 时列出全部候选
mask不该翻译的部分换成 placeholder
任务
  1. 读入 precompile.tex，UTF-8 严格解码；文中已经出现哨兵 ⟦ ⟧ 即 mask_failed——placeholder 靠这两个字符唯一
  2. 判定每个环境：先扫一遍全文，数出每个 \begin{X} 的出现次数，收集文内的 \newtheorem / \newenvironment / \renewenvironment 声明。每个环境按序查：文内声明过 → text；environments.json 有条目（X* 查不到退回 X）→ 取表里的 class 与 category；都没有 → non_translatable / unknown。判定与来源记进 manifest 的 environments
  3. 摘 block：第二遍扫描，每个不译区域整块摘走，masked.tex 里换成 ⟦BLK-n⟧，原文进 blocks.json。摘的是：
    • preamble：文件头到 \begin{document}；postamble：\end{document} 到文件尾
    • comment：注释——连续的整行注释合成一块，行尾注释单独一块
    • math：$$…$$、\[…\]；行内 $…$ 与 \(…\) 留在正文里不摘
    • non_translatable 环境：按表的 category（math / table / figure / tikz / code / algorithm / bibliography / box / unknown），嵌套时整个外层一块
    • metadata：\title \author \date \affiliation \email 的花括号参数
    text 环境（theorem 一族、abstract、center…）透明：\begin / \end 留在正文，只摘它里面的块。\verb 跳过不摘。每块记下 category、环境名、判定来源、内含的 \label、字符区间与行号
  4. 抽 caption：block 里仍要翻的文字单独抽出成 ⟦CAP-n⟧——figure / table 等块内的 \caption{…}、\captionof{…}{…}，以及前导区里的 abstract 环境正文（revtex 一类把摘要写在前导区）。块的原文里该位置换成 ⟦CAP-n⟧；masked.tex 里紧跟 ⟦BLK-n⟧ 另起一行放「⟦CAP-n⟧ 压成单行的 caption 原文」，让它跟正文一起送翻。code 类块不抽 caption
  5. 往返自检：unmask(masked.tex, blocks.json) 与 precompile.tex 逐字符恒等；不等即 mask_failed，message 给出第一处差异的位置与上下文
  6. 写 masked.tex 与 blocks.json。没遇到 \end{document} 记一条 warning，不算失败

class MaskManifest(Manifest):
    status: MaskStatus
    environments: dict[str, EnvironmentDecisionRecord]   # 按环境名，本篇出现过的每个环境怎么判的
    blocks_total: int
    captions_total: int
    precompile_chars: int
    masked_chars: int
    masked_chars_ratio: float

class EnvironmentDecisionRecord(BaseModel):
    classification: "text"|"non_translatable"
    category: BlockCategory | None    # non_translatable 时的类别；text 为 None
    decided_by: "newtheorem"|"newenvironment"|"table"|"default"   # 判据来源：文内定义、environments.json 表、缺省
    occurrences: int
    blocks: int

# ===== build/blocks.json —— placeholder 与原文的映射；survey 取 abstract，compile 回填 =====
class BlocksFile(BaseModel):
    blocks: list[BlockRecord]
    captions: list[CaptionRecord]

class BlockRecord(BaseModel):
    id: str                          # BLK-n
    category: "math"|"table"|"figure"|"tikz"|"code"|"algorithm"|"bibliography"|"box"|"unknown"|"preamble"|"postamble"|"comment"|"metadata"
    environment: str                 # 环境名；前导区、注释等非环境 block 为空
    decided_by: "newtheorem"|"newenvironment"|"table"|"default" | None   # 环境 block 的判定来源；其余为 None
    labels: list[str]               # block 内的 \label
    tex: str                         # 原文，回填用
    start: int; end: int              # 在 precompile.tex 字符序列上的区间
    line: int

class CaptionRecord(BaseModel):
    id: str                          # CAP-n
    block_id: str                    # 所属 block；abstract 不在任何 block 里时为空
    kind: "caption"|"abstract"
    tex: str                         # 原文整条命令 / 环境
    masked_text: str                 # tex 压成单行；masked.tex 里跟在 ⟦CAP-n⟧ 后面送翻的就是它
survey通览全文，产出翻译任务单ask（可选）
任务
  1. 切 chunk：扫标题结构选首选层级 → 按章节切 → 大于 SPLIT_ABOVE 下分、小于 MERGE_BELOW 合并 → 定区 front / body / appendix → 自检拼接恒等。token 数用 tiktoken（o200k_base）实数
  2. 模型提议术语表（可选，角色 survey_terms，--no-terms 或角色未配置时跳过）：一次 ask，输入摘要 + 标题树 + 全文掩码文本，schema 约束输出 {terms, do_not_translate}；模型不可用降级为空提议并记 warning，不是失败。提议的译名机械补空格：中文字符与 ASCII 字母数字相邻处插一个空格（细粒度token选择 → 细粒度 token 选择），用户三层的译名原样不动
  3. 合并四层术语表：模型提议（最低层 survey）→ 全局配置目录 → 论文工作目录 → 命令行 --glossary，后者覆盖前者；按全文命中过滤，未命中记 filtered；用户 style 段原样转录。terms 与 do_not_translate 的区别就是词写在了输入文件的哪一段。命中规则：词边界匹配，允许尾缀 s / es；全大写的词（缩写）区分大小写，其余不区分——LLM 命中 LLM / LLMs，不命中 vLLM / llm；large language model 命中 Large Language Models。 去重按归一化键：casefold、空白与连字符折成单个空格、去掉词尾 es/s（与命中规则认复数的口径一致），LLM 与 LLMs 是同一条。 复合术语：一条术语的原词里以整词形式含有某个 do_not_translate 词时，它的译名必须原样含有该词（mixed RL training 译作「混合 RL 训练」，不是「混合强化学习训练」）。 两类冲突（同键冲突、复合术语丢词）同一套处置：双方都来自用户层（全局 / 论文 / 命令行）→ 两条都保留，只记 warning 请用户自己改；一方来自 survey 提议、另一方来自用户层 → 丢 survey 那条并记 warning；双方都来自 survey → do_not_translate 胜出并记 warning。跨层同键是覆盖不是冲突，后层照常覆盖前层
  4. 取全局语境：照录摘要（blocks.json 的 abstract 槽位或 masked.tex 的 abstract 环境）；章节标题树
  5. 写 brief.json（上面三样合一）与 chunks/

术语提议是跨 chunk 一致性的预防手段：所有 chunk 的 system 里从一开始就是同一份词；而且它是产物（brief.json），翻译前可以打开改两条再跑。治疗手段是 review 阶段。

# ===== build/brief.json —— translate 只读这一个文件加 chunks/ =====
class BriefFile(BaseModel):
    abstract: str | None                   # 论文原文摘要照录；两条来路都落空为 null（不是失败，记一条 warning）
    heading_tree: list[Heading]             # 全文章节标题树，按文档序；一个标题都没有为空列表
    terms: list[TermEntry]
    do_not_translate: list[DoNotTranslateEntry]
    style: str | None                      # 用户写给译者的额外要求；三层都没写为 null
    chunks: list[ChunkRecord]

# 一条标题。全文树与 chunk 内清单用同一个类，chunk 内的 depth 也如实填。
class Heading(BaseModel):
    command: str                  # 标题命令名：section / subsection / …（星号变体等同无星）
    argument: str                 # 标题参数原文，未翻译
    depth: int                    # 相对深度：全文最浅层级记 1，往深一级加一

class TermEntry(BaseModel):
    word: str                     # 原写法，取胜出层的
    translation: str              # 本篇译法，translate 按它约束用词
    decided_by: "survey" | "global" | "paper" | "cli"   # 胜出层，survey 是模型提议的最低层

class DoNotTranslateEntry(BaseModel):
    word: str
    decided_by: "survey" | "global" | "paper" | "cli"

class ChunkRecord(BaseModel):
    id: str                       # c012
    start: int; end: int           # 在 masked.tex 字符序列上的区间，文件内容即该切片
    part: "front"|"body"|"appendix"
    tokens: int                   # tiktoken 实数，只用于分块决策
    paragraphs: int
    headings: list[Heading]       # chunk 内有效深度 0 的标题，按文档序
    translatable_chars: int       # 剥除 placeholder 后的非空白字符数；0 即纯 placeholder，不调模型

# ===== build/manifests/survey.json =====
class SurveyManifest(Manifest):
    status: SurveyStatus
    chunks_total: int
    transparent_environments: list[str]   # 切 chunk 时当作可穿透的环境名
    terms_total: int
    do_not_translate_total: int
    filtered: list[FilteredTerm]       # 全文未命中、被过滤掉的术语

class FilteredTerm(BaseModel):
    word: str
    decided_by: "survey" | "global" | "paper" | "cli"

# ===== GlossaryFile —— 三层术语表文件共用的格式；不是 pydantic model，survey 手工解析，任何字段类型不对即 glossary_invalid =====
{
  "terms": {"原文写法": "本篇译法", …},      # 可省；空译法不允许
  "do_not_translate": ["原文写法", …],     # 可省；同层内同一个词既在 terms 又在这里即 glossary_invalid（大小写不敏感）
  "style": "写给译者的额外要求"            # 可省；多层都写时靠后层覆盖
}
translate逐 chunk 调模型翻译，脚本驱动校验与重试askuser 是「请翻译：」加围栏包住的待译正文；重试是多轮续写，至多 1 次
任务（每个 chunk，线程池并发，结果按文档序落盘）
  1. translatable_chars 为 0 → skipped，原文即译文，不调模型。这种 chunk 只有 placeholder 与空白（比如整段都是公式、图表的区域，或只有 \maketitle 一类命令）
  2. 组装 system（稳定部分在前、本 chunk 特有部分在后，见右）与 user（只有待译正文）
  3. ask，拿回译文；整段包在代码围栏里时剥掉围栏
  4. 四层 validate（见下），全过 → translated
  5. 不过 → 在同一段对话后续两轮（assistant = 上一次译文，user = 差异说明 + 请重新输出完整译文）再 ask 一次；ask 报错或返回空则直接再 ask 一次（不带差异说明）。无论原因，每 chunk 至多 2 次 ask，第二次之后必定得出 translated 或 fallback
  6. 仍不过 → fallback，译文文件写原文，记最后一次未通过的层
  7. 全部跑完后一次写出 build/translated/（中途被杀不留半套产物）；回退多少都照常写出——回退件是原样的合法 LaTeX，编译得过，有 review 时由它补翻；每个回退的 chunk 在 warnings 记一条（chunk id + 最后一次未通过的层）。translate_failed 只留给配置错、读不到输入、写出后自检不过这类失败（2026-08-25 拍板，原先的 0.2 比例门与 fallback_ratio 一并去掉）；不提前中断（中断只会丢掉已翻译的 chunk）
四层 validate —— 全是机械比对，不含判断；失败信息写成人读的差异说明，原样回灌给模型
层比什么差异说明长什么样
placeholders⟦BLK-n⟧ / ⟦CAP-n⟧ 的 multiset 相等；另查 ⟦ ⟧ 数量与完整 placeholder 数吻合（拦 ⟦BLK-3⟧⟧ 这类碎片）「译文缺少 ⟦BLK-12⟧；多出 ⟦BLK-21⟧」
control_sequences控制序列 multiset 相等：取 \cmd 的命令名，带紧随的星号（\section* ≠ \section）；\% 一类符号控制序列取符号本身「\cite 原文 3 次、译文 2 次；\emph 原文 0 次、译文 1 次」
braces_and_math未转义的 { } 配对平衡（深度不转负、结尾归零）；未转义的 $ 偶数且不少于原文；未转义的 % 不多于原文（裸 % 把该行后半截整个注释掉，别的层抓不到）；分节命令（\section 一族与 \paragraph 一族）后的空行两侧规范化后再比段数（这类空行不改变渲染，2412.19437 的 c007 曾因此整块回退）「{ } 在第 312 字符处不平衡」「$ 原文 14 个、译文 12 个」
paragraph_count含可译文本的段落数相等。一段剥除 placeholder、\begin{X} / \end{X}、其余命令名之后仍有非空白字符才计入——模型合并只含 placeholder 或只含 \maketitle 的空行不算错「原文 9 段、译文 8 段」

字体配置models.toml 的 [fonts] 表，precompile 注入中文排版设置时读取

fonts切换译文 PDF 的中文字体，改 models.toml 即生效，无命令行选项已实现
规则
  1. 四个槽位：main 正文、bold 粗体（BoldFont）、sans 无衬线、mono 等宽。sans 不写则按平台探测（Hiragino Sans GB → Noto Sans CJK SC → 霞鹜文楷），mono 不写则用 main
  2. 取值两类：字体文件——.ttf / .otf / .ttc，写仓库 fonts/ 里的文件名或一个文件路径（可用 ~），precompile 把文件拷进编译树的 fonts/，以 Path={fonts/} 相对引用，编译树保持自包含；系统字体名——不带扩展名即视为字体名，由 fontspec 按名字查找
  3. main / sans / mono 可写成列表按序回退（同 CSS 的 font-family）：每个字体名候选包一层 \IfFontExistsTF，存在就用，不存在试下一个；文件候选必然可用、终止链条，它之后的候选不会被用到（写 warning）；候选全是字体名时，末尾自动补默认霞鹜文楷作为最后一级回退。单个字体名不包检测，写错由编译失败暴露
  4. bold 是单值，与候选同类（文件配文件、字体名配字体名）才配对；默认的 bold 只与默认的 main 配对，不跟随换掉的字体；与所有候选都配不上时写 warning 并忽略
  5. 失败不抛异常：配置的字体文件不存在则跳过该候选并写进 manifest 的 warnings，候选全部不可用时用默认字体
