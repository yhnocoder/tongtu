通途设计文档

通途把 arXiv 论文的 LaTeX 源码翻译成中文，编译出保留原文排版与公式的 PDF。设计文档分三份：流水线写七个阶段的任务、状态与产物，模型调用层写 ask / work 与 models.toml，命令行写命令、选项与重跑规则。

  • ask(role, system, messages) AskOutcome
    work(role, workdir) WorkOutcome
    [runtime.codex] command = [...]
    [roles] translate = { runtime = "codex" }
