命令行

tongtu 是通途的命令行入口：给它一个 arXiv 编号，它下载论文源码、翻译成中文、编译出与原版排版相同的 PDF。日常只用 tongtu run 一条命令。其余命令配合它使用：status 查看一篇论文的各阶段状态，stage 单独重跑某个阶段，validate 校验一对译文，doctor 检查环境，setup 生成配置。七个阶段各自做什么见 pipeline.html，模型与服务商的配置见 model.html。

SYNOPSIS

tongtu run      PAPER [--from STAGE] [--no-review] [OPTIONS]
tongtu stage    [STAGE PAPER] [OPTIONS]
tongtu status   PAPER [--workdir DIR]
tongtu validate SRC DST
tongtu doctor
tongtu setup    [-i]
tongtu          --version

PAPER 是 arXiv 编号、arXiv 链接或本地源码目录。STAGE 取 fetch、precompile、mask、survey、translate、review、compile 之一。终端输出、manifest 的 message 与 warnings 一律英文；发给模型的素材与 models.toml 模板注释不在此列。

COMMANDS 示例输出为示意

run PAPER [--from STAGE] [--no-review]
翻译一篇论文，生成与原版排版相同的中文 PDF。依次运行 fetch → precompile → mask → survey → translate → review → compile。每个阶段结束后终端输出一行结果（✓/✗ 阶段 状态 摘要 耗时）；阶段的 message 与 warnings 各占一行，缩进在结果行下方。
某阶段失败停在出错的阶段，退出 1，终端输出原因与 manifest 路径。修好后再执行一次同样的命令，就从这个阶段接着跑，前面的阶段不重做。
被打断同上：再执行一次，从中断的阶段接着跑。
七个阶段都已跑完什么也不做，退出 0，提示用 --from。
改了输入要重跑加 --from STAGE，从该阶段起重跑，先删掉它及其下游的旧产物。改了什么就从哪个阶段起：src/ 里的源码或 models.toml 的 [fonts] → precompile；tongtu/data/environments.json → mask；任一层术语表或分块参数 → survey；skill/translate/SKILL.md → translate；skill/review/ → review。tongtu 不检测输入是否变化，不给 --from 就沿用旧产物。

从头到尾跑一篇。

$ tongtu run 2412.19437 workdir /Users/zach/.local/share/tongtu/2412.19437 stage status summary elapsed ✓ fetch ok tar.gz, 14 tex files 0:00:02 ✓ precompile ok 12 pages 0:00:41 ✓ mask ok 183 blocks masked 0:00:00 ✓ survey ok 17 chunks, 23 terms 0:00:09 ✓ translate ok 17 chunks, 1 fallback 0:06:12 warning: c003 fell back to the English source; the last attempt failed: control_sequences: \cite appears 3 times in source, 2 in translation ✓ review ok 0:11:40 ✓ compile ok 12 pages, baseline 12 0:00:47 $ echo $? 0

进度显示。每个阶段运行时占一行进度行（只在终端是 tty 时刷新），结束后换成结果行。precompile、survey、review、compile 显示当前动作；translate 显示每个 chunk 的进度与已完成数、token 数、耗时、预计剩余时间。回退的 chunk 各输出一行持久 warning，保留在进度行上方，例如 warning: c003 fell back to the English source after 2 attempts。阶段模块不直接向终端打印，通过 report 回调把状态交给命令行层渲染。

stage STAGE PAPER
只运行一个阶段，用于反复调整某一步，例如改了 translate 的 SKILL.md 后只看译文的变化，不重跑 review 与 compile。它先删掉本阶段的旧产物再运行，不改动其他阶段的产物，之后要继续往下就用 run。上游产物不在时拒绝执行，退出 2。选项与 run 相同，但没有 --from 与 --no-review。不带参数运行 tongtu stage，按顺序列出七个阶段名。

只跑 translate，本次换一个模型。

$ tongtu stage translate 2412.19437 --ask-model opencode/gpt-5.6-luna --ask-effort low stage status summary elapsed ✓ translate ok 17 chunks 0:04:31
status PAPER
查看一篇论文各阶段的状态：每个阶段一行，列出状态、产物是否存在、manifest 路径；manifest 的 message 与 warnings 列在该行下方。上次运行失败后想先了解原因再决定是否重跑，用它；更详细的记录在 logs/。只读，不改任何文件。

compile 失败，查看原因。

$ tongtu status 2512.02556 workdir /Users/zach/.local/share/tongtu/2512.02556 stage status outputs manifest fetch ok present build/manifests/fetch.json precompile ok present build/manifests/precompile.json inlined main.bbl at the \bibliography command mask ok present build/manifests/mask.json survey ok present build/manifests/survey.json abstract not found: no abstract slot in blocks.json and no abstract environment in masked.tex; the brief carries abstract = null. translate ok present build/manifests/translate.json c004 fell back to the English source; the last attempt failed: control_sequences: \cite appears 3 times in source, 2 in translation review ok present build/manifests/review.json compile compile_failed absent build/manifests/compile.json 47 pages against a baseline of 31 (ratio 1.52) falls outside [0.7, 1.3]
validate SRC DST
检查一份译文是否破坏了原文结构：给原文与译文两个文件，逐层输出 pass / fail 与差异（placeholders、control_sequences、braces_and_math、paragraph_count）。手工修改译文后用它确认；translate 与 review 内部运行的是同一套校验。

逐层输出结果。

$ tongtu validate build/chunks/c004.tex build/translated/c004.tex [pass] placeholders [fail] control_sequences: \cite appears 3 times in source, 2 in translation; \emph appears 0 times in source, 1 in translation [pass] braces_and_math [pass] paragraph_count $ echo $? 1
doctor
检查环境，逐项输出 ok / missing：TeX 工具链（xelatex、TeX Live 不低于 2026、latexmk、latexpand）、中文字体（只看仓库 fonts/ 下的两个霞鹜文楷文件，不检查用户的 [fonts] 配置）、models.toml、[roles] 引用的服务商密钥与 agent 运行时可执行文件（运行时条目引用的服务商一并检查）。安装环境后先运行它。工具链或字体缺失退出 1；配置与密钥的问题只报告，不影响退出码，最后一行说明从 survey 起的阶段不能运行。

全部齐全：退出 0。

setup [-i]
第一次使用前运行一次，生成配置文件 models.toml（带注释的模板，已存在不覆盖，权限 0600）。-i：逐个询问是否启用模板里的服务商并输入 API key（不回显），API 直调类角色指向第一个启用的服务商，模型换成该服务商的默认模型；一个都没启用退出 2。不加 -i 就自己打开文件填写。

第一次使用：写出配置、填入密钥。

$ tongtu setup -i configure opencode? [y/N]: y API key for opencode: configure deepseek? [y/N]: n configure anthropic? [y/N]: n wrote /Users/zach/.config/tongtu/models.toml.

OPTIONS run 与 stage 共用；stage 不含 --from 与 --no-review

--from STAGE
从哪个阶段起重跑，见 run。
--ask-model PROVIDER/MODEL，--ask-effort LEVEL
本次换一个模型做 API 直调：覆盖所有 ask 类角色（survey_terms、API 模式的 translate）。PROVIDER 是 models.toml 里 [provider.*] 的名字。要长期更换或只换一个角色，改 models.toml。
--work-model RUNTIME/MODEL，--work-effort LEVEL
本次换一个模型做 agent 工作：覆盖所有 agent 会话（work）类角色（Agent 模式的 translate、review、precompile_fix、compile_fix）。RUNTIME 是 [runtime.*] 的名字，例如 codex/astra。
--glossary FILE
给这篇论文额外指定术语表，可多次给出，靠后的优先。与全局层、论文层术语表叠加。
--no-terms
不让模型提议术语，只用自己给出的术语表。
--no-review
只 run 有。跳过审校会话，行为见 review 卡。
--jobs N
translate 同时翻译的 chunk 数，默认 4。
--workdir DIR
把这篇论文的工作目录放到指定位置。默认 $TONGTU_HOME/<编号>，再默认 ~/.local/share/tongtu/<编号>。

EXIT STATUS

0
成功。run：PDF 已写出，或七个阶段的产物都在；validate：四层全部通过；doctor：工具链与字体齐全。
1
某阶段失败，manifest 里有原因；validate 某层不通过；doctor 工具链或字体缺失。
2
用法错误；stage 的上游产物不在；setup -i 一个服务商都没选；TONGTU_DISABLE 已设置。

FILES

~/.config/tongtu/models.toml
服务商、模型清单、各角色默认模型，见 模型调用层。
~/.config/tongtu/glossary.json
全局层术语表。
<工作目录>/glossary.json
论文层术语表。
<工作目录>/src/ build/ logs/ out/
各阶段的输入与产物，见各阶段卡片；manifest 在 build/manifests/<stage>.json。

取值优先级，右边覆盖左边：模型与强度 = models.toml [roles] → --ask-* / --work-*；术语表 = 模型提议 → 全局层 → 论文层 → --glossary；工作目录 = ~/.local/share/tongtu/ → $TONGTU_HOME → --workdir。

ENVIRONMENT

TONGTU_HOME
工作目录根。
XDG_CONFIG_HOME
配置目录根，默认 ~/.config。
服务商密钥
服务商条目 api_key 留空时，用其 api_key_env 指定的环境变量。
TONGTU_DISABLE
已设置时入口立刻退出 2。work 会话的子进程环境里设置它，让会话内的 tongtu run 明确失败。

EXAMPLES run 与 stage 在各种情况下的行为；输出为示意

某阶段失败：停在该阶段，输出 message 与 manifest 路径，退出 1。

$ tongtu run 2512.02556 workdir /Users/zach/.local/share/tongtu/2512.02556 stage status summary elapsed ✓ fetch ok tar.gz, 9 tex files 0:00:01 ✓ precompile ok 31 pages, 1 fix session 0:04:58 ✓ mask ok 412 blocks masked 0:00:01 ✓ survey ok 29 chunks, 41 terms 0:00:14 ✓ translate ok 29 chunks 0:09:03 ✓ review ok 0:14:20 ✗ compile compile_failed 0:01:12 47 pages against a baseline of 31 (ratio 1.52) falls outside [0.7, 1.3] manifest /Users/zach/.local/share/tongtu/2512.02556/build/manifests/compile.json $ echo $? 1

不改任何输入再执行一次：从失败的阶段接着跑，上游产物不动。

$ tongtu run 2512.02556 workdir /Users/zach/.local/share/tongtu/2512.02556 resuming from compile (upstream outputs present) stage status summary elapsed ✓ compile ok 33 pages, baseline 31 0:01:05 $ echo $? 0

改了术语表，从 survey 重跑：先删掉 survey 及其下游产物。

$ tongtu run 2512.02556 --from survey --glossary ~/terms/moe.json workdir /Users/zach/.local/share/tongtu/2512.02556 --from survey: removed survey and downstream outputs stage status summary elapsed ✓ survey ok 29 chunks, 46 terms 0:00:13 …

七个阶段的产物都在：什么也不做。

$ tongtu run 2412.19437 workdir /Users/zach/.local/share/tongtu/2412.19437 all seven stage outputs are present; nothing to run. Use --from STAGE to redo.

上游产物不在：退出 2，不写 manifest。

$ tongtu stage compile 2512.02556 upstream outputs absent: translate, review. Run tongtu run first, or tongtu run --from translate to redo. $ echo $? 2

不带参数：列出阶段名。

$ tongtu stage fetch → precompile → mask → survey → translate → review → compile

在 work 会话里误运行：入口立刻退出 2。

$ TONGTU_DISABLE=1 tongtu run 2412.19437 tongtu cannot run inside an agent session (TONGTU_DISABLE is set)
